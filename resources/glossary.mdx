This glossary defines technical terms you'll encounter across Yantra Commons documentation and project files. Bookmark it for reference as you explore and build.

---

| Term | Definition |
|------|------------|
| **BOM (Bill of Materials)** | A spreadsheet listing every component in a project: reference designator, description, value, quantity, and supplier part numbers. Each Yantra Commons project includes a `hardware/BOM.csv` in the repository. |
| **CERN OHL** | CERN Open Hardware Licence. A family of open licenses designed specifically for hardware designs. Three variants exist: Permissive (P), which has minimal restrictions; Weakly Reciprocal (W), which requires sharing modifications to the covered design; and Strongly Reciprocal (S), which extends share-alike requirements more broadly. All Yantra Commons projects use one of these three variants. |
| **Component Footprint** | The physical layout of pads, holes, and silkscreen markings on a PCB that corresponds to a specific component package (e.g., SOT-23, 0402, DIP-8). The footprint tells the PCB manufacturer exactly where to place copper and drill holes for a given component. |
| **DRC (Design Rule Check)** | An automated verification pass in KiCad (and other EDA tools) that checks the PCB layout against a set of manufacturing constraints — minimum trace width, minimum clearance between nets, annular ring size, and so on. Running a clean DRC is a required step before generating Gerbers for fabrication. |
| **EDA (Electronic Design Automation)** | Software used to design electronic circuits and PCBs. KiCad is the EDA tool used for all Yantra Commons hardware projects. |
| **Gerber Files** | The standardized file format (RS-274X) used by PCB fabrication houses to manufacture printed circuit boards. A Gerber set typically includes one file per copper layer, plus files for solder mask, silkscreen, and board outline. Generated from the PCB layout in KiCad and found at `hardware/gerbers/` in each project repository. |
| **KiCad** | A free and open-source electronics design automation (EDA) suite used to create schematics and PCB layouts. KiCad is the tool used for all Yantra Commons hardware design files. Project files use the `.kicad_sch` and `.kicad_pcb` formats. |
| **MCU (Microcontroller Unit)** | A compact integrated circuit that contains a processor core, program and data memory, and programmable I/O peripherals on a single chip. The MCU is the "brain" of most Yantra Commons devices — it runs the firmware and controls all connected hardware. |
| **Net** | An electrical connection between two or more component pins in a schematic. Every net has a name (e.g., `VCC`, `GND`, `UART_TX`) and represents a wire or plane that must be routed on the PCB. |
| **OSHWA** | Open Source Hardware Association. The organization that defines the open source hardware definition and administers the OSHWA Certification program, which allows hardware projects to display the OSHWA logo when they meet the open source hardware standard. |
| **PCB (Printed Circuit Board)** | A flat board, typically made of FR4 fiberglass, that mechanically supports and electrically connects electronic components using conductive copper tracks, pads, and planes. PCBs are manufactured by specialist fabrication houses using Gerber files. |
| **PlatformIO** | An open-source build system and IDE extension for embedded firmware development. Used in most Yantra Commons projects to compile and upload firmware. PlatformIO manages toolchains and library dependencies via the `platformio.ini` configuration file in the `firmware/` directory. |
| **Planned Obsolescence** | The deliberate design of products to fail, degrade, or become incompatible after a predictable period, in order to drive repeat purchases. One of the core problems that Yantra Commons addresses: by publishing open designs, we make hardware that can be repaired, upgraded, and understood indefinitely. |
| **Pull Request (PR)** | A GitHub mechanism for proposing changes to a repository. Contributors fork the repository, make their changes on a branch, and open a PR to request that the changes be merged into the main project. The standard way to contribute improvements to any Yantra Commons project. |
| **Reference Designator** | An alphanumeric label that uniquely identifies a specific component instance on a schematic and PCB (e.g., `R1` for the first resistor, `C3` for the third capacitor, `U2` for the second integrated circuit). Reference designators link the schematic to the PCB layout to the BOM. |
| **Schematic** | A diagram using standardized graphical symbols to represent the electrical connections in a circuit, without regard to physical placement or scale. Schematics are the primary way to understand how a Yantra Commons circuit works. Each project includes a human-readable `hardware/schematic.pdf` and an editable KiCad source file (`hardware/schematic.kicad_sch`). |
| **SMD / SMT** | Surface-Mount Device / Surface-Mount Technology. A PCB assembly method where components are soldered directly onto pads on the surface of the board, rather than through holes. SMD components are generally smaller and cheaper than through-hole equivalents but require more skill or specialized equipment (reflow oven, hot air) to solder by hand. |
| **STEP File** | A standard 3D CAD exchange file format (.step or .stp), defined by ISO 10303. Used to share mechanical models between different CAD applications. Yantra Commons projects often include STEP files for the PCB assembly so you can design an enclosure around it. |
| **STL** | A 3D file format (originally from stereolithography) widely used for 3D printing. Yantra Commons enclosure designs are provided as STL files in the `enclosure/` directory (e.g., `enclosure/enclosure.stl`) and can be sliced directly in software like PrusaSlicer, Cura, or Bambu Studio. |
| **Through-Hole** | A PCB component assembly technique where component leads are inserted through drilled holes in the board and soldered on the opposite side. Through-hole components are larger than SMD equivalents but are significantly easier to solder by hand, making them the preferred choice for Beginner-tagged projects. |
| **Toolchain** | The complete set of software tools required to compile source code into a binary, and upload it to a microcontroller. In Yantra Commons projects using PlatformIO, the toolchain is managed automatically based on the `board` and `framework` settings in `platformio.ini`. |
| **UART** | Universal Asynchronous Receiver-Transmitter. A common serial communication protocol that transmits data one bit at a time over TX (transmit) and RX (receive) lines. Widely used in embedded systems for debug output (via a serial monitor), communication between microcontrollers, and interfacing with peripheral modules such as GPS receivers and Bluetooth adapters. |
