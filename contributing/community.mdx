## How to Ask for Help

The Yantra Commons community is friendly and welcoming to all skill levels — whether you're assembling your first PCB or debugging a complex firmware issue, you're in the right place.

When asking a technical question, help the community help you by including:

- **Your hardware** — which Yantra Commons project you're building, which revision of the files you're using, and any modifications you've made.
- **Your operating system and toolchain** — for firmware and software issues, include your OS, IDE version, and compiler or flasher version.
- **Relevant error messages** — paste the full error output, not just the last line. If it's long, use a GitHub Gist or a code block.
- **A link to the exact step you're stuck on** — link directly to the project repository and, if possible, the specific section of `BUILD.md` or `FIRMWARE.md` where you hit the problem.

The more context you provide upfront, the faster and more accurately the community can respond.

## Code of Conduct

Yantra Commons follows an open, respectful community standard. All participants are expected to:

- Be kind and patient — everyone was a beginner once.
- Assume good faith in others' questions and contributions.
- Critique designs, not people — feedback should address the work, not the person.
- Actively help newcomers get their first build working.

The full Code of Conduct is published at [github.com/yantracommons](https://github.com/yantracommons) as `CODE_OF_CONDUCT.md`. Violations can be reported to maintainers through GitHub.

## Meetups and Events

Yantra Commons organises periodic in-person events in Bengaluru, including:

- **Build workshops** — guided sessions where participants assemble a Yantra Commons project together, with support from experienced builders.
- **Hardware hackathons** — time-boxed design sprints focused on a specific open hardware challenge.
- **Open hardware talks** — presentations and discussions on topics in open hardware, repair culture, and electronics design.

Event announcements are posted on the [Yantra Commons GitHub organisation](https://github.com/yantracommons) and in the community channels. If you're outside Bengaluru and want to organise a local Yantra Commons event or build session, let the community know — we'll help you promote it and connect you with others in your region.

## Staying Updated

To keep up with new projects, releases, and announcements:

- **Watch the yantracommons GitHub organisation** — click **Watch** on the organisation page to receive notifications for new repositories and announcements.
- **Subscribe to release notifications** on the specific projects you care about — click **Watch → Custom → Releases** on any project repository to be notified whenever a new version is published.
- **Follow GitHub Discussions** in repositories where you're active — new discussions and replies will appear in your GitHub notifications feed.

<Tip>
  New to open hardware? Don't hesitate to introduce yourself in the GitHub Discussions — the community loves to help newcomers get their first build working. Share what you're hoping to build and someone will point you in the right direction.
</Tip>
